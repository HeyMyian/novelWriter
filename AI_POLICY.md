# AI Policy

This is the AI policy of novelWriter. Contributions violating this document will not be accepted into this project.


### Code Contributions

We consider code as creative work, and we have a strong preference for feature contributions designed by actual humans
over the average and mediocre results of generative AI.

While we do not have a strict No-AI policy, we do expect any contributed code to hold up to maintainability and
stability standards so that our users can rely on the software for their creative work. This implies careful reviews,
thorough test coverage, and beta testing of all features before they reach live users. The requirements on code that
isn't shipped to the user is less strict. This includes unit tests and build tooling.

Our take on AI tooling is that it can be an assisting tool alongside other tools that can edit or add code. Using it for
boilerplate, fixes, and otherwise editing and extending existing code, is fine. However, you must not contribute fully
or predominately AI-generated features or other bulk-generated code. This applies especially to core functionality.

In general, our code quality requirements are requirements that so-called vibe coding does not deliver, so this project
is not suitable for such contributions in any case. The licensing implications around generated code are also unclear,
as AI models are trained on material without consent or concern for original licensing.

No AI automation or agentic tools is used anywhere in this project on GitHub. Do not use your AI agents on your
contributions on GitHub either. Commits listed as authored by, signed off by, or assisted by, AI tools are not allowed.
Pull requests containing such commits will be rejected. AI-specific files are not allowed into the code repository. Most
of the common ones are in the git ignore file.


### Design Work

No design work generated by AI for novelWriter will be accepted. We do not control how third party work like icon
libraries are created, but any artwork added to the app must be made by actual people.


### Translation Work

This project uses Crowdin to host the translation files for the user interface. Crowdin has a lot of AI integration and
tooling, but we don't use any of it beyond the translation suggestions provided to our translators by their basic AI
tool. All translations are proofread and approved by speakers of the respective languages.


### Application Features

We do not believe creative writing and generative AI go together. Therefore there will not be any tooling added to this
project that will generate text for you. Language models have a real use case in text analysis that predates generative
AI, and such supportive tools **may** be in scope depending on how intrusive they are.


### Discussions and Comments

Please refrain from using AI to generate responses to discussions, issues, and pull requests. Do not use AI tools to
generate long and verbose issue reports. It is OK to use AI for translations of comments or for accessibility reasons.
All posted text should be in English.
